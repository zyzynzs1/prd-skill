# 公文格式排版规范（gongwen-format）

> **何时读取**：阶段 6 交付、把 Markdown 转成 Word 之前必读；任何需要调整 Word 字体、字号、页边距、行距、页码时读取。
>
> **依据**：GB/T 9704-2012《党政机关公文格式》及机关通行执行口径整理。PRD 不是正式公文，本规范只约束**版式**（用纸、版心、字体、字号、行距、页码、表格图片、附件），不要求红头、发文字号、印章、抄送等公文要素。
>
> 参考：[GB/T 9704-2012 条文摘录（保山学院）](http://jjsc.bsnc.cn/info/1010/1596.htm)、[党政机关公文格式（常州工学院）](https://dzbgs.ccit.edu.cn/info/1006/1861.htm)、[公文排版开源实现](https://github.com/pamelaaaaa1218/gongwen-format-skill)。

## 1. 用纸与版心

| 项目 | 规范 |
|---|---|
| 用纸 | A4（210 mm × 297 mm），70 g/m² 及以上 |
| 版心 | 156 mm × 225 mm |
| 页边距 | 上 3.7 cm，下 3.5 cm，左 2.8 cm，右 2.6 cm |
| 页脚 | 距页面下边缘 2.8 cm |
| 装订线 | 0 cm（左侧装订） |
| 行数/字数 | 一般每面 22 行、每行 28 字，并撑满版心 |
| 行距 | 正文固定值 **28.5 磅**（在 28～29 磅之间按“每面 22 行”校准）；标题行距固定值 40 磅 |
| 文字颜色 | 黑色（技能规定的【待确认】红色标注除外） |

## 2. 字体、字号总表

字号换算：二号 = 22 pt，三号 = 16 pt，四号 = 14 pt，小四 = 12 pt，五号 = 10.5 pt。

| 位置 | 中文字体 | 字号 | 其它要求 |
|---|---|---|---|
| 文档标题 | 方正小标宋简体 | 二号（22 pt） | 居中，可多行，回行词意完整、梯形或菱形排列；行距固定值 40 磅 |
| 正文 | 仿宋_GB2312 | 三号（16 pt） | 首行缩进 2 字，回行顶格；两端对齐；段前段后 0 |
| 一级标题「一、」 | 黑体 | 三号（16 pt） | 不加粗；段前 0.5 行、段后 0 |
| 二级标题「（一）」 | 楷体_GB2312 | 三号（16 pt） | 不加粗；段前 0.5 行、段后 0 |
| 三级标题「1.」 | 仿宋_GB2312 | 三号（16 pt） | **加粗**；段前段后 0 |
| 四级标题「（1）」 | 仿宋_GB2312 | 三号（16 pt） | 不加粗；段前段后 0 |
| 附件说明「附件：」 | 仿宋_GB2312 | 三号（16 pt） | 正文下空一行、左空二字；多个附件用阿拉伯数字编号 |
| 附件内容首页左上角「附件」 | 黑体 | 三号（16 pt） | 附件内容本身用字与正文相同 |
| 页码 | 宋体 | 四号（14 pt） | 半角阿拉伯数字，两侧各一条一字线（如 `— 1 —`）；奇数页右空一字，偶数页左空一字 |
| 数字与英文 | Times New Roman | 随所在段落 | 仅西文/数字用 Times New Roman，中文仍用上表字体 |
| 表格 | 表头黑体、内容仿宋_GB2312 | 五号（10.5 pt） | 表内行距单倍、段前段后 0；表格居中、段前 0.5 行；跨页时重复表头 |
| 图片与图注 | 图注楷体_GB2312 | 五号（10.5 pt） | 图片居中，宽度不超过版心 15.6 cm；图注在图下居中 |

> 字体缺失时按回退链替换，并在交付说明中记录：方正小标宋简体 → 华文中宋 → 宋体加粗；仿宋_GB2312 → 仿宋（FangSong）；楷体_GB2312 → 楷体（KaiTi）；黑体 → 黑体（SimHei）。

## 3. PRD 标题层级 → 公文层级映射

PRD 沿用自己的中文编号体系，不强行改成公文序号；**只按下列对应关系套用字体字号**：

| PRD Markdown | Word 层级 | 采用字体字号 |
|---|---|---|
| `# 《产品名》产品需求文档` | 文档标题 | 二号方正小标宋简体，居中 |
| `## 一、…` | 一级标题 | 三号黑体 |
| `### 1、…` | 二级标题 | 三号楷体_GB2312 |
| `#### 迭代N功能描述` | 三级标题 | 三号仿宋_GB2312 加粗 |
| `##### N、大功能点`、`##### 附件：…` | 四级标题 | 三号仿宋_GB2312 |
| 普通段落 | 正文 | 三号仿宋_GB2312，首行缩进 2 字 |
| 两列功能表、清单表 | 表格 | 五号仿宋_GB2312，表头五号黑体 |

## 4. 段落与缩进

1. 正文每个自然段左空二字（首行缩进 2 字符 ≈ 32 pt @ 三号），回行顶格。
2. 段前段后 0，行距固定值 28.5 磅；不得用“1.25 倍”“单倍”等相对行距替代正文行距。
3. 各级标题独立成行、不加项目符号；标题文字不手工加粗（三级标题除外，按上表加粗）。
4. 表格内段落行距必须为**单倍**，否则固定行距会把表格撑得很高。
5. 表格、图片所在段落不得设置首行缩进。

## 5. 表格、图片与附件

### 5.1 表格
- 表格居中，宽度撑满版心或按内容列宽；全表五号字，表头黑体五号、内容仿宋_GB2312 五号。
- 表内行距单倍、段前段后 0；表头行跨页重复。
- 单元格内换行用段落换行，不使用 `<br>` 文本。

### 5.2 图片
- 图片居中，宽度不超过版心 15.6 cm；原型图建议 7～9 cm，框架图建议 15 cm。
- 图注置于图下，五号楷体_GB2312、居中；图片不得超出页面边界。

### 5.3 附件
- 正文下空一行、左空二字写「附件：名称」；多个附件按「附件：1. ×××」编号。
- 附件首页左上角标「附件」（三号黑体）；附件内容用字与正文相同。
- **测试用例附件必须是嵌入 Excel 对象**：每个迭代 1 个 xlsx（4 个工作表：正常流程 / 异常操作 / 边界条件 / 权限校验，8 列表头），插入该迭代附件位；正文与附录区**不得**出现用例表格、用例截图或 Markdown 表格。附件位由「四级标题 + 一行说明 + 嵌入对象」组成，用例条数增加不得增加 Word 页数。
- 嵌入对象的预览图应能看清「附件名称 + 工作表名称/条数 + 双击打开」提示；对象宽度不超过版心。

## 6. Word 实现要点（python-docx / WPS）

```python
from docx.shared import Cm, Pt
from docx.enum.text import WD_LINE_SPACING, WD_ALIGN_PARAGRAPH
from docx.oxml.ns import qn

# 页面设置
sec = doc.sections[0]
sec.page_width, sec.page_height = Cm(21), Cm(29.7)
sec.top_margin, sec.bottom_margin = Cm(3.7), Cm(3.5)
sec.left_margin, sec.right_margin = Cm(2.8), Cm(2.6)
sec.footer_distance = Cm(2.8)

# 中文字体必须同时设置 eastAsia / ascii / hAnsi
def set_run_font(run, cn, size_pt, bold=False):
    run.font.name = 'Times New Roman'
    run.font.size = Pt(size_pt)
    run.bold = bold
    rPr = run._element.get_or_add_rPr()
    rFonts = rPr.get_or_add_rFonts()
    rFonts.set(qn('w:eastAsia'), cn)
    rFonts.set(qn('w:ascii'), 'Times New Roman')
    rFonts.set(qn('w:hAnsi'), 'Times New Roman')

# 正文固定行距 + 首行缩进 2 字（三号 2 字 = 32 pt）
p.paragraph_format.line_spacing_rule = WD_LINE_SPACING.EXACTLY
p.paragraph_format.line_spacing = Pt(28.5)
p.paragraph_format.first_line_indent = Pt(32)
p.paragraph_format.space_before = Pt(0)
p.paragraph_format.space_after = Pt(0)
```

- 页码：设置 `w:evenAndOddHeaders`，奇数页页脚右对齐、偶数页页脚左对齐，内容为 `— PAGE 域 —`，宋体四号。
- 表格：`table.autofit = True`，表头行设置 `tblHeader`；单元格段落行距单倍。
- 交付前用真实字体环境（有 WPS/Word 的机器）打开核对；字体缺失时按回退链处理并记录。
