# PRD 写作风格：去 AI 味（writing-style）

> **何时读取**：阶段 4「分迭代起草」与阶段 6「交付前润色」必读；尤其改写功能描述、具体说明、功能框架图节点时。
>
> 目标不是“像人说话”，而是**可执行、无歧义、能验收**。PRD 不需要口语毛刺、第一人称、故意不整齐；表格、字段顺序、编号层级是规范，不能为了“自然”打乱。

## 1. 一句话判据

> 这句话换个项目名、换个模块，还成立吗？成立就是空话。

四道自检：

1. **主语**：这件事谁做的？说不出角色 → 删或补。
2. **对象**：对什么做的？说不出页面、字段、记录、文件 → 补。
3. **边界**：为空、失败、超限、无权限时怎么办？没有边界就是没写完。
4. **朗读**：一口气读不完或要换气 → 拆句。

## 2. 词表

### 2.1 见到就删（Tier 1）

赋能、闭环、全链路、全场景、端到端、一体化、抓手、底层逻辑、颗粒度、顶层设计、数智化、降本增效、提质增效、生态、矩阵、范式、飞轮、势能、心智、组合拳、护城河。

### 2.2 密集才删（Tier 2，一段出现三个以上再处理）

核心、关键、重要、全面、高效、智能、便捷、灵活、稳定、可靠、安全、完善、丰富、强大、领先、显著、大幅、明显、有效。

### 2.3 套话 → 具体说法

| 套话 | 改成 |
|---|---|
| 赋能 / 助力 | 让……能做……；帮……省掉…… |
| 闭环 | 不合格能退回；处理完有回执 |
| 全链路 / 端到端 | 从 X 到 Y 的每一环（写出 X、Y） |
| 打通 | 接上；A 的数据直接进 B |
| 沉淀 | 存下来；留成记录 |
| 对齐 | 确认一致 |
| 落地 / 上线 | 上线；在某版本可用 |

### 2.4 动词替换

| 别写 | 写成 |
|---|---|
| 实现了 / 完成了 / 进行了 / 确保了 | 点击、保存、跳转、退回、锁定、导出、提示 |
| 支持 XX 的新增、编辑、删除与查询 | 能新建、能改、能删、能查（各自条件写清） |
| 保障 / 承载 / 支撑 XX | 谁在用、用来干什么 |
| 提升 / 优化 XX 效率 | 原来几步，现在几步 |
| 统一管理 | 在同一个页面里改，改完所有引用处生效 |

## 3. 六种必改句式

1. **三段并列 / 排比**：可监控、可追溯、可交付 → 只留能验收的一条，其余拆句。
2. **连接号串流程**：扫描采集—图像生产—校对质检 → 角色 + 动作 + 交接物。
3. **不仅…而且 / 不是…而是 / 通过…实现 / 旨在** → 直接说事实。
4. **无主语名词化**：完成了统一管理 → 谁在哪个页面改，保存后什么生效。
5. **中译腔**：通过对 X 进行 Y，实现对 Z 的提升 → 改 X，Z 就变；该 / 其 / 被字句、逗号拖到底都要拆。
6. **破折号堆叠 / 括号补充**：该补的另起一句；一个括号只放一个信息（单位、取值范围）。

## 4. PRD 四个高危位置

1. 功能描述第一句写成身份口号（“系统统一入口，供全部角色使用”）——改成“谁、在什么情况下、打开哪个页面、做什么”。
2. 功能描述结尾自评（“解决……问题”“提升……效率”“保障……可追溯”）——删掉，写成规则或验收项。
3. 几十个页面复制同一段模板话——相同规则抽到章节开头写一次，页面内只写差异。
4. 每节末尾的过渡与总结（综上、由此可见、总的来说）——删。

## 5. 具体化：形容词 → 可验收的事实

| 空话 | 换成 |
|---|---|
| 显著提升 / 大幅改善 | 原来 X，现在 Y；或“不超过 N 秒” |
| 快速响应 / 及时提示 | 点击后立即；或 N 毫秒内 |
| 支持多种格式 | 列出来：一次 SHT、二次 SHT、空白检测规则、裁切格式 |
| 完善 / 优化 | 原来怎么做，现在怎么做 |
| 大量 / 海量 | 具体数字，或“超过 N 条时【待确认】” |
| 友好 / 清晰 / 合理 | 不写；写具体文案、位置、顺序 |

补不出事实时写【待确认】，不要用抽象词糊过去。

## 6. 功能框架图节点专用五条（x.y.z 能力点同样适用）

1. 节点名 = **角色 + 动作 + 产出**，12 字以内；写“扫描员出图”“质检员判图”，不写“图像采集能力”。
2. 箭头要有**交接物**（重扫工单、转图批次、图像包），不写“数据流转”。
3. 不用“一体化 / 闭环 / 全链路 / 中台 / 底座”当节点名。
4. 分支节点写**判定条件**（合格 / 不合格、有条码 / 无条码），不写“异常处理”。
5. 节点说明里出现两个以上「管理 / 管控 / 支撑」就重写：换成“谁点哪个按钮，生成什么记录”。

## 7. 验收四条

- [ ] 遮住项目名，这句话还成立吗？成立 → 仍是空话。
- [ ] 每句都能回答“谁做的”吗？
- [ ] 至少有一个具体名词（字段名、按钮名、文件类型、数字）吗？
- [ ] 删完以后句子骨架明显变短了吗？只换词、段落长度不变，就是机械执行。
